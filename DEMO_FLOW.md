# SIH Judge Demo Flow  — 7–10 minutes

Use `npm run seed-demo` before the demo if a deterministic demonstration dataset is desired. Every seeded record is marked **DEMONSTRATION DATA**.

1. **Citizen / Community** — enter the citizen workspace (`citizen.demo@jharkhandi.local` as the local demo identity) and submit a water challenge with severity, urgency, population, GPS/evidence.
2. **AI intake** — open the challenge cockpit and show trained domain classification, confidence, top alternatives, priority and summary.
3. **Challenge DNA** — show structured context; explain that  persists provenance/review metadata for derived fields.
4. **Problem Family** — show the related/duplicate family and explain that merge remains a human decision.
5. **Root cause** — switch to Government and review/edit root-cause hypotheses;  stores reasoning/evidence/confidence/source/review state.
6. **Historical solution retrieval** — use Decision Intelligence. Seeded memory contains successful, partial and failed water projects.
7. **Reuse / Adapt / Invent + transferability** — show the recommendation and local adaptations; explain that  stores factor-level assumptions/incompatibilities and does not claim statistical prediction.
8. **Failure learning** — show the cloud-only connectivity failure record and its offline-fallback lesson.
9. **Matching** — show University and Industry matches generated from stored capability profiles, labs, mentor/funding/pilot capacity.
10. **Proposal + pre-mortem** — submit a proposal; show structured risks, evidence/reason, likelihood/impact bands and mitigations.
11. **Delivery** — show milestones/tasks/deliverables, budget, risk register, prototype/testing/pilot/deployment evidence.
12. **Impact integrity** — enter baseline/post metrics and evidence; explain claimed vs verified state, then Government verifies.
13. **Innovation Memory** — close the project and show the structured memory record being reused by a similar future challenge.
