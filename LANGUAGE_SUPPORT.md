# Language support

Jharkhandi separates **interface language** from **challenge content language**.

A citizen can select a language for the public website/workspace and separately submit the actual challenge in a supported Jharkhand language. The original Unicode title and description are preserved in the challenge record.

## Editorial status
**Full editorial packs bundled:** English, Hindi, Bengali, Bhojpuri, Magahi, Maithili, Urdu and Odia.

**Community-draft packs:** Angika, Bhumij, Ho, Kharia, Khortha, Kurmali, Kurukh, Mundari, Nagpuri and Santali.

Community-draft packs deliberately preserve globally recognised technical decision terms such as Challenge DNA, REUSE / ADAPT / INVENT and Innovation Memory in bilingual form where a verified local equivalent is not bundled. This avoids silently inventing official terminology.

Before an official statewide rollout, community-draft packs should be reviewed by native speakers and Jharkhand language experts.

## NLP behaviour
The original citizen report is always preserved. The local classifier uses multilingual keyword normalization for common societal-domain terms and exposes confidence. Government reviewers can correct the final domain; corrections are stored as supervised feedback and incorporated in later local model training.

## Urdu
Urdu activates RTL document direction and RTL layout adjustments.
